How it works

Most of this score is deterministic. We check, we don't guess.

01

Crawl

Fetch up to 10 pages the way an answer-engine crawler does — no JavaScript — plus robots.txt, your sitemap and the well-known paths agents look for.

02

Technical audit

Bot allowlists, schema.org coverage, heading structure, render-without-JS, llms.txt, Content Signals. Pure checks — no model involved, so the same site scores the same twice.

03

Score

Five pillars, 100 points. Anything we couldn't measure is excluded from the total and named, rather than quietly counted as zero.

04

Write the fixes

Generate the real artifact for each gap — the JSON-LD, the llms.txt, the robots.txt diff — built only from content we actually read on your site. Anything we can't source comes back as an obvious placeholder instead of a guess.
